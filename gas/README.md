# 煎和鍋貼｜線上訂單串接 Google Sheet（Google Apps Script）

官網結帳送出的訂單，會即時寫進 Google 試算表，並寄通知信給店家。

```
官網結帳 ──POST──▶ Google Apps Script（Code.gs）──▶ Google 試算表
                         │                            ├─ 訂單（一筆訂單一列，含狀態）
                         │                            ├─ 訂單明細（一個品項一列）
                         └─▶ 新訂單通知信             └─ 每日統計（公式自動計算）
```

> 程式碼最上方的 `CONFIG.SPREADSHEET_ID` 已填入「煎和鍋貼｜線上訂單」試算表的 ID，
> 訂單一律寫到這份試算表，就算 Apps Script 是從別的地方建立的也沒關係。
> 若要改寫到其他試算表，把 ID 換掉即可（試算表網址 `/d/` 和 `/edit` 中間那一段）。

## 一、建立試算表與程式（約 5 分鐘）

1. 打開試算表「煎和鍋貼｜線上訂單」（Google 雲端硬碟中，或自己新建一個空白試算表）。
2. 上方選單 **擴充功能 → Apps Script**。
3. 刪掉編輯器裡預設的 `function myFunction() {}`，把本資料夾 **`Code.gs` 的全部內容**貼上，按 💾 儲存。
4. 上方函式選單選 **`setup`** → 按 **▶ 執行**。
   - 第一次會要求授權：選你的 Google 帳號 →「進階」→「前往（不安全）」→「允許」。
     （這是你自己寫的程式，Google 只是提醒尚未經過審核。）
   - 完成後回到試算表，會看到「訂單」「訂單明細」「每日統計」三個工作表。
5. （選用）`setup` 會自動把選單掛到訂單試算表上；重新整理試算表後，上方會出現 **🥟 煎和鍋貼** 選單，可以按「測試：建立一筆範例訂單」確認寫入正常，之後把測試列刪掉即可。

## 二、部署成網頁應用程式

1. Apps Script 編輯器右上角 **部署 → 新增部署作業**。
2. 齒輪 ⚙ 選 **網頁應用程式**，設定：
   - 說明：`官網訂單 API`
   - 執行身分：**我**
   - 具有存取權的使用者：**所有人**
3. 按 **部署**，複製「網頁應用程式網址」（`https://script.google.com/macros/s/……/exec`）。
4. 把網址填進 `index.html` 的這一行（或把網址交給 Claude 處理）：

   ```js
   const ORDER_API_URL = 'https://script.google.com/macros/s/……/exec';
   ```

   填入後，結帳下方的「此為模擬結帳流程」會自動改成正式訂購說明。

> **之後修改 Code.gs 時**：要到 **部署 → 管理部署作業 → ✏ 編輯 → 版本選「新版本」→ 部署**，網址不變，改動才會生效。直接存檔不會更新線上版本。

## 三、日常使用

| 想做的事 | 怎麼做 |
|---|---|
| 處理訂單 | 在「訂單」工作表把「狀態」改成 製作中／可取餐／已出貨／已完成／已取消，「狀態更新時間」會自動記錄 |
| 看今天賣多少 | 「每日統計」工作表（已排除已取消訂單），或選單「寄送今日營收報表給我」 |
| 每天自動寄報表 | Apps Script 左側 ⏰ **觸發條件 → 新增觸發條件**：函式 `sendTodayReport`、時間驅動、每日、晚上 9–10 點 |
| 改通知信收件人 | `Code.gs` 最上方 `CONFIG.NOTIFY_EMAIL` 填入 Email（留空＝寄給部署者）；不想收信改 `SEND_NOTIFY_EMAIL: false` |
| 查詢訂單狀態 | 開啟 `網頁應用程式網址?orderNo=JH261127-001&phone=0912345678`（需同時提供訂單編號與手機） |

## 四、注意事項

- **價格以 Code.gs 為準**：程式會用 `PRODUCTS` 重新計算金額，不採用網頁送來的價格，避免被竄改。
  **官網改價格或新增商品時，`Code.gs` 的 `PRODUCTS` 也要一起改**（並重新部署新版本），否則該商品會無法下單。
- **防濫用**：同一支手機 10 分鐘內最多 5 筆訂單；表單有隱藏的機器人陷阱欄位；以 `=`、`+`、`-`、`@` 開頭的文字會自動加上單引號，避免試算表公式注入。
- **訂單編號**：格式 `JH年月日-流水號`（例：`JH261127-007`），由伺服器產生，同時下單也不會重複。
- **配額**：免費 Google 帳號每天約可寄 100 封信、網頁應用程式每天可處理數萬次請求，一般店家足夠使用。
- `appsscript.json` 為選用：若想縮小授權範圍，可在 Apps Script「專案設定」勾選「在編輯器中顯示 appsscript.json」後貼上。
